# Adarsh Mishra — QA Automation Engineer & Founder Portfolio

A modern, highly responsive developer portfolio built with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**. Designed specifically to showcase dual strengths in **QA Test Automation & Web3 Testing** alongside **Full-Stack AI Product Building (SkillTa & Mail-Karo)**.

## ✨ Features & Architecture
- **Responsive & Modern Design:** Mobile-first layout with smooth navigation, glassmorphism cards, glowing mesh backgrounds, and neon cyberpunk/cyan accents.
- **Hero & Live Avatar:** Displays public profile photo (`https://github.com/Code-By-Adarsh.png`) with animated glowing rings and an interactive test execution log terminal.
- **Metrics Bar:** Highlights key accomplishments (108+ Test Cases, 96.3% STLC accuracy, 50+ Career Roadmaps, 2+ Internships).
- **Interactive Skills Matrix:** Categorized into:
  - *Automation Testing* (Selenium, Playwright, TestNG, POM, Maven, Extent/Allure)
  - *Manual QA & Methodologies* (STLC, BVA, EP, Negative Testing, Jira Defect Triage, RTM)
  - *API & Web3 QA* (Postman, REST APIs, MetaMask, Sepolia Testnet, MySQL)
  - *Software Dev & AI* (Java, JavaScript/TypeScript, Next.js, Gemini API, Tailwind CSS)
- **Experience Timeline:** Detailed cards for **Stellar Code (Web3 QA)**, **ConnektSphere (QA Tester Intern)**, and **SkillTa (Founder & Lead Developer)**.
- **Projects Showcase:** Filterable tabs (*All*, *Full-Stack & AI*, *QA Automation*, *Manual QA & STLC*) with live links, GitHub links, and metric badges.
- **Verified Credentials:** Official certificates from Postman, Google Gemini, LinkedIn Learning, and ISRO Hackathon.
- **Interactive Contact:** Direct copyable email, WhatsApp/Phone link, and working contact form.

## 🚀 Running Locally

1. Install dependencies (if not already installed):
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Production Build
```bash
npm run build
npm run start
```
